Download for Windows

Windows 10 or 11, 64-bit. The installer is signed, so Windows shows the publisher when you run it.

Getting set up

  1. Install from your own accountSign in to Windows with your (administrator) account and run the installer.
  2. Follow the setup wizardIt opens by itself. It sets up a standard Windows account for each child (or uses the ones they have), asks for a parent PIN, and helps you choose limits, breaks and bedtimes.
  3. Hand the PC backWhen your kids next sign in, PlayPacer shows them what it does and how much time they have. That's it.
Already use Microsoft Family? The wizard spots it and offers to leave the daily limit to Microsoft Family, while PlayPacer adds breaks and bedtime.
